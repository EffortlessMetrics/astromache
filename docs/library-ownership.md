# Source ownership

EffortlessMetrics/astromache owns the AstroMache publication template and its astromache package. Offline source is owned independently by https://github.com/EffortlessMetrics/astro-offline; this producer and its optional recipe consume the exact unpublished0.1.2 archive. No packages/offline implementation remains here.

Contact source remains EffortlessMetrics/turnstile-contact. Type-anywhere search source remains the private EffortlessMetrics/type-anywhere-search repository. Static-search extraction is prepared in private EffortlessMetrics/static-search PR1; it remains gated on genuine independent approval of Search PR21. Existing static-search consumer bytes stay unchanged until that gate and extraction review are satisfied.

Private sites consume template components and the libraries using stable exported APIs; content, origin, corpus, cache policy and deployment remain consumer-owned. No private site source or history is imported into public products.
